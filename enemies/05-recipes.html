Recipes: five enemies

Five complete monsters, each with a different way to fight it. Every state, transition and number is here, written the way the studio stores it, so you can build each one field by field in the workshop and play it straight away.

You'll learnhow the pieces of this track combine into real designs: a ranged-and-melee imp, a charger you sidestep, a turret you outflank, a sniper you chase down, and a boss that changes as it is hurt Time60 minutes, or 10 for one recipe Needsthe whole Enemies track; a sprite sheet for each monster; small props for the missiles; a few sounds in a sound pack

Reading a recipe

Each recipe is the monster's table as the studio writes it into maps/module.lua. Every key is a field you can see in the workshop:

  • the top keys (hp, sight, pain_chance …) are on 🧠 brain; vars is # vars; swing is 🌀 swing;
  • each entry of states is a box in the graph. Its fields are on its ⬡ tab, transitions are the cards under ❓ go to … when all of …, and sequence is the list under ▶ at tick … do …;
  • negate = true is the not switch beside a condition;
  • numbers in quotes, such as "1.3333", are exact decimals. Type them as they are.

Sound names are from the DOOM II module's bank. Pick your own pack's sounds in their place. Particle kinds (effect, hit_vfx, tracer) are numbers from your module's ✨ Particles; the recipes mark them with a comment.

Remember the two timing rules from The brain: a monster decides every 8 ticks, and a state's sequence is first looked at 8 ticks after it was entered. The recipes put their at values on multiples of 8, so what you read is what happens.

1. The imp: claws close, fireballs far

Doom's imp, from the engine's own DOOM monsters, with Doom's map units turned into world units (48 to one). It stands until it sees you, shouts, then walks at you. Close up it claws; at range, once it is lined up, it throws a fireball you can sidestep. The order of chase's cards is the design: claw first, because when both hold the claw is the right answer.

missiles = {
  fireball = {
    speed = "7.2917", gravity = 0, life = 300, z_offset = "0.6667",
    anim_fly = 0, anim_burst = 1, burst_ticks = 20,
    on_hit = {
      { action = "damage", amount = 12 },
      { action = "sound", name = "missile.fireball.burst", from = "impact" },
    },
  },
},
mobs = {
  imp = {
    hp = 60, pain_chance = 200, turn_speed = 12, sight = "42.6667",
    mass = 100, infighting = true, corpse = true,
    initial = "look",
    vars = { ready = 0 },
    states = {
      look = { anim = 0, move = "stop", face = "hold",
        transitions = {
          { to = "alert", when = { { cond = "has_target" }, { cond = "target_visible" } } },
        } },
      alert = { anim = 1, move = "stop", face = "target", ticks = 1, next = "chase",
        sequence = { { at = 0, action = "sound", name = "monster.imp.sight" } } },
      chase = { anim = 1, move = "chase", face = "target", interruptible = true,
        transitions = {
          { to = "look", when = { { cond = "has_target", negate = true } } },
          { to = "claw", when = { { cond = "target_within", distance = "1.3333" },
                                  { cond = "target_visible" },
                                  { cond = "cooldown_ready", var = "ready" } } },
          { to = "throw", when = { { cond = "target_within", distance = "42.6667" },
                                   { cond = "target_visible" },
                                   { cond = "target_in_front", arc = 12 },
                                   { cond = "cooldown_ready", var = "ready" } } },
        } },
      claw = { anim = 2, move = "stop", face = "target", ticks = 32, next = "chase", interruptible = true,
        sequence = {
          { at = 0,  action = "face" },
          { at = 16, action = "melee", damage = 9, range = "1.3333" },
          { at = 16, action = "sound", name = "monster.imp.melee" },
          { at = 16, action = "set_cooldown", var = "ready", ticks = 94 },
        } },
      throw = { anim = 2, move = "stop", face = "target", ticks = 32, next = "chase", interruptible = true,
        sequence = {
          { at = 0,  action = "face" },
          { at = 16, action = "missile", kind = "fireball", offset = "0.8333" },
          { at = 16, action = "sound", name = "missile.fireball.launch" },
          { at = 16, action = "set_cooldown", var = "ready", ticks = 94 },
        } },
      pain = { anim = 3, move = "stop", face = "hold", ticks = 7, next = "chase",
        sequence = { { at = 0, action = "sound", name = "monster.pain.small" } } },
      death = { anim = 4, move = "stop", face = "hold", solid = false, ticks = 51, next = "death",
        sequence = { { at = 0, action = "sound", name = "monster.imp.death" } } },
    },
  },
}
  • Body: radius 0.4167, height 1.1667, speed 5.83 (Doom's numbers). The fireball needs a prop called fireball, radius 0.125, with state 0 flying and state 1 bursting.
  • Why target_in_front 12: a shot goes where the body points. Without it the imp throws while half turned, into the wall beside you.
  • One cooldown for both attacks: a claw delays the next fireball and the other way round, which keeps the imp from doing both at once.
  • Make it yours: set blood to a green particle kind; it bleeds green whatever hits it.

2. The charger: a wind-up, then a straight dash

It stalks you, stops, glows, then commits to a straight line at three times its speed. If it reaches you it gores you hard. If you step aside, it runs past, or into a wall, and stands there winded: that is your moment.

The trick is the straight line. move = "chase" would steer after you. Instead, at the end of the wind-up it stores your direction in the var wander with set_angle, and the dash uses move = "wander", which walks that stored heading and nothing else. The speed comes from an effect on move_speed.

charger = {
  hp = 120, pain_chance = 60, turn_speed = 8, sight = "30", mass = 400,
  infighting = true, corpse = true,
  initial = "look",
  vars = { charge_ready = 0, wander = 0 },
  states = {
    look = { anim = 0, move = "stop", face = "hold",
      transitions = {
        { to = "stalk", when = { { cond = "has_target" }, { cond = "target_visible" } } },
      } },
    stalk = { anim = 1, move = "chase", face = "target", interruptible = true,
      transitions = {
        { to = "gore", when = { { cond = "target_within", distance = "1.4" } } },
        { to = "windup", when = { { cond = "target_within", distance = "10" },
                                  { cond = "target_visible" },
                                  { cond = "target_in_front", arc = 15 },
                                  { cond = "cooldown_ready", var = "charge_ready" } } },
      } },
    windup = { anim = 2, move = "stop", face = "target", ticks = 40, next = "dash", interruptible = false,
      sequence = {
        { at = 0,  action = "telegraph", effect = 20, radius = "1", ticks = 32 },  -- effect: your warning particle kind
        { at = 0,  action = "sound", name = "monster.pinky.sight" },
        { at = 32, action = "set_angle", var = "wander", towards = "target" },
        { at = 32, action = "face", towards = "var", var = "wander" },
        { at = 32, action = "effect", param = "move_speed", mul = "3", ticks = 64, tag = "dash" },
      } },
    dash = { anim = 1, move = "wander", face = "hold", ticks = 48, next = "tired", interruptible = false,
      transitions = {
        { to = "gore",  when = { { cond = "target_within", distance = "1.6" } } },
        { to = "tired", when = { { cond = "stuck", ticks = 16 } } },
      } },
    gore = { anim = 2, move = "stop", face = "target", ticks = 16, next = "tired", interruptible = false,
      sequence = {
        { at = 0, action = "melee", damage = 25, range = "1.8", knockback = "14", lift = "4" },
        { at = 0, action = "sound", name = "monster.pinky.melee" },
      } },
    tired = { anim = 0, move = "stop", face = "hold", ticks = 64, next = "stalk", interruptible = true,
      sequence = { { at = 0, action = "set_cooldown", var = "charge_ready", ticks = 180, jitter = 60 } } },
    pain = { anim = 3, move = "stop", face = "hold", ticks = 12, next = "stalk" },
    death = { anim = 4, move = "stop", face = "hold", solid = false, ticks = 100, next = "death" },
  },
}
  • Body: radius 0.5, speed 3.5. The dash runs at 10.5.
  • The wind-up cannot be flinched out of (interruptible = false), so the player must dodge, not shoot it off course. tired can, so hits during the opening make it stagger.
  • The telegraph's ticks (32) are the time from the warning (8 ticks in) to the dash (40).
  • stuck ends a dash into a wall early, so it does not grind against it for the full 48 ticks.

3. The turret: slow to turn, quick to shoot

It never moves. It tracks you slowly, and fires a three-round burst when you are in front of it. You beat it by moving faster than it turns, or by staying out of its line. It has no pain state, so it never flinches.

turret = {
  hp = 150, turn_speed = "0.5", sight = "24", mass = 1000,
  infighting = false, corpse = true,
  initial = "scan",
  vars = { ready = 0 },
  states = {
    scan = { anim = 0, move = "stop", face = "hold",
      transitions = {
        { to = "track", when = { { cond = "has_target" }, { cond = "target_visible" } } },
      } },
    track = { anim = 0, move = "stop", face = "target",
      transitions = {
        { to = "fire", when = { { cond = "target_visible" },
                                { cond = "target_in_front", arc = 6 },
                                { cond = "cooldown_ready", var = "ready" } } },
        { to = "scan", when = { { cond = "target_visible", negate = true },
                                { cond = "state_elapsed", ticks = 32 } } },
      } },
    fire = { anim = 2, move = "stop", face = "target", ticks = 32, next = "track",
      sequence = {
        { at = 8,  action = "hitscan", damage = 6, range = "24", spread = 3 },
        { at = 8,  action = "sound", name = "weapon.pistol.fire" },
        { at = 16, action = "hitscan", damage = 6, range = "24", spread = 3 },
        { at = 24, action = "hitscan", damage = 6, range = "24", spread = 3 },
        { at = 24, action = "set_cooldown", var = "ready", ticks = 60, jitter = 12 },
      } },
    death = { anim = 4, move = "stop", face = "hold", solid = true, ticks = 100, next = "death",
      sequence = { { at = 0, action = "sound", name = "missile.rocket.burst" } } },
  },
}
  • Body: radius 0.5, height 1, speed 0, solid. Its death sets solid = true, so the wreck still blocks.
  • turn_speed "0.5" is half a turn per second, slow enough to outrun by strafing.
  • Why state_elapsed 32 on the way back to scan: without it, the turret drops you the moment a pillar crosses its line, and snaps back the moment it clears. Half a second of patience reads as "watching".
  • The three shots are at 8, 16 and 24, the first three decisions in the state. ticks is 32 because a step must come before the state ends: the server refuses a step at or after the state's ticks.

4. The sniper: keeps its distance

It wants you at middle range. Too far, it closes in. Too near, it backs away while still facing you. In range and in sight, it aims for most of a second, with a warning, then fires one heavy shot and sidesteps. You beat it by rushing it, or by breaking its line while it aims.

sniper = {
  hp = 40, pain_chance = 180, turn_speed = 8, sight = "40",
  infighting = true, corpse = true,
  initial = "look",
  vars = { ready = 0 },
  drops = { { item = "ammo_clip" } },
  states = {
    look = { anim = 0, move = "stop", face = "hold",
      transitions = {
        { to = "approach", when = { { cond = "has_target" }, { cond = "target_visible" } } },
      } },
    approach = { anim = 1, move = "chase", face = "target", interruptible = true,
      transitions = {
        { to = "backoff", when = { { cond = "target_within", distance = "6" } } },
        { to = "aim", when = { { cond = "target_within", distance = "30" },
                               { cond = "target_visible" },
                               { cond = "cooldown_ready", var = "ready" } } },
      } },
    backoff = { anim = 1, move = "flee", face = "target", ticks = 48, next = "approach", interruptible = true,
      transitions = {
        { to = "aim", when = { { cond = "target_within", distance = "6", negate = true },
                               { cond = "target_visible" },
                               { cond = "cooldown_ready", var = "ready" } } },
        { to = "aim", when = { { cond = "stuck", ticks = 24 } } },
      } },
    aim = { anim = 2, move = "stop", face = "target", ticks = 48, next = "shoot", interruptible = true,
      sequence = {
        { at = 0, action = "telegraph", effect = 21, radius = "0.5", ticks = 40 },  -- effect: your warning particle kind
      },
      transitions = {
        { to = "approach", when = { { cond = "target_visible", negate = true } } },
        { to = "backoff",  when = { { cond = "target_within", distance = "4" } } },
      } },
    shoot = { anim = 2, move = "stop", face = "target", ticks = 16, next = "reposition",
      sequence = {
        { at = 0, action = "face" },
        { at = 0, action = "hitscan", damage = 30, range = "40", spread = 0 },
        { at = 0, action = "sound", name = "weapon.shotgun.fire" },
        { at = 0, action = "set_cooldown", var = "ready", ticks = 150, jitter = 30 },
      } },
    reposition = { anim = 1, move = "strafe", face = "target", ticks = 40, ticks_jitter = 24, next = "approach",
      interruptible = true },
    pain = { anim = 3, move = "stop", face = "hold", ticks = 10, next = "backoff" },
    death = { anim = 4, move = "stop", face = "hold", solid = false, ticks = 100, next = "death" },
  },
}
  • Body: radius 0.35, speed 4.5: a little slower than the player, so rushing works.
  • flee with face = "target" backs away while still looking at you, as Doom's monsters do. stuck catches it backing into a wall: cornered, it shoots anyway.
  • The aim is cancelled if you break its line or rush within 4. That is the counterplay, and the order of aim's two cards does not matter because they cannot both hold for long.
  • Pain goes to backoff, so a hit both flinches it and makes it retreat.
  • The drop needs a prop called ammo_clip with a pickup of the same name, or change it to one of yours.

5. The boss: two phases by health

A big, slow warden. In phase one it stomps if you come close and throws a fan of three blast orbs at range. Below half health it roars once, calls its minions, gets faster and throws heavier volleys. The phase lives in a var, phase, so every way back into the fight (after a stomp, a volley or a flinch) goes through one small state, regroup, that picks the right chase.

missiles = {
  warden_orb = {
    speed = "9", gravity = 0, life = 240, z_offset = "1.2",
    anim_fly = 0, anim_burst = 1, burst_ticks = 20,
    on_hit = {
      { action = "damage_area", damage = 20, radius = "1.5", falloff = true, hurts_owner = false },
      { action = "sound", name = "missile.rocket.burst", from = "impact" },
    },
  },
},
mobs = {
  warden = {
    hp = 1500, pain_chance = 30, turn_speed = 6, sight = "50", mass = 1000,
    pain_time = { per_damage = "0.2", max = 20 },
    infighting = false, corpse = true,
    initial = "look",
    vars = { ready = 0, phase = 1 },
    swing = { damage = 30, reach = "2.5", half_arc = "0.25", sweep_from = "0", sweep_to = "0",
              ticks = 6, pitch_from = "0.125", pitch_to = "-0.125", half_pitch = "0.0625",
              knockback = "16", lift = "6" },
    states = {
      look = { anim = 0, move = "stop", face = "hold",
        transitions = {
          { to = "chase1", when = { { cond = "has_target" }, { cond = "target_visible" } } },
        } },
      chase1 = { anim = 1, move = "chase", face = "target", interruptible = true,
        transitions = {
          { to = "enrage", when = { { cond = "hp_below", percent = 50 }, { cond = "var_is", var = "phase", value = 1 } } },
          { to = "stomp", when = { { cond = "target_within", distance = "2.5" },
                                   { cond = "target_above", by = "1", negate = true },
                                   { cond = "cooldown_ready", var = "ready" } } },
          { to = "volley", when = { { cond = "target_within", distance = "40" },
                                    { cond = "target_visible" },
                                    { cond = "target_in_front", arc = 12 },
                                    { cond = "cooldown_ready", var = "ready" } } },
        } },
      chase2 = { anim = 1, move = "chase", face = "target", interruptible = true,
        transitions = {
          { to = "stomp", when = { { cond = "target_within", distance = "2.5" },
                                   { cond = "target_above", by = "1", negate = true },
                                   { cond = "cooldown_ready", var = "ready" } } },
          { to = "summon", when = { { cond = "count_within", distance = "20", at_least = 1, mob = "imp", negate = true },
                                    { cond = "chance", percent = 5 } } },
          { to = "storm", when = { { cond = "target_visible" },
                                   { cond = "target_in_front", arc = 12 },
                                   { cond = "cooldown_ready", var = "ready" } } },
        } },
      stomp = { anim = 2, move = "stop", face = "target", ticks = 40, next = "regroup", interruptible = false,
        sequence = {
          { at = 0,  action = "telegraph", effect = 20, radius = "2.5", ticks = 16 },  -- effect: your warning particle kind
          { at = 24, action = "swing" },
          { at = 24, action = "set_cooldown", var = "ready", ticks = 60 },
        } },
      volley = { anim = 2, move = "stop", face = "target", ticks = 32, next = "regroup", interruptible = true,
        sequence = {
          { at = 0,  action = "face" },
          { at = 16, action = "missile", kind = "warden_orb", count = 3, arc = 15, offset = "1.2" },
          { at = 16, action = "set_cooldown", var = "ready", ticks = 90, jitter = 20 },
        } },
      enrage = { anim = 2, move = "stop", face = "target", ticks = 48, next = "regroup", interruptible = false,
        sequence = {
          { at = 0,  action = "set_var", var = "phase", value = 2 },
          { at = 0,  action = "sound", name = "monster.cyberdemon.sight" },
          { at = 0,  action = "effect", param = "move_speed", mul = "1.5", tag = "enraged" },
          { at = 0,  action = "alert_nearby", radius = "30" },
          { at = 24, action = "spawn", mob = "imp", count = 2, limit = 4, offset = "2", jitter = "1" },
        } },
      summon = { anim = 2, move = "stop", face = "target", ticks = 40, next = "regroup",
        sequence = { { at = 16, action = "spawn", mob = "imp", count = 2, limit = 4, offset = "2", jitter = "1" } } },
      storm = { anim = 2, move = "stop", face = "target", ticks = 48, next = "regroup", interruptible = true,
        sequence = {
          { at = 0,  action = "face" },
          { at = 8,  action = "missile", kind = "warden_orb", count = 5, arc = 12, offset = "1.2" },
          { at = 24, action = "face" },
          { at = 24, action = "missile", kind = "warden_orb", count = 5, arc = 12, offset = "1.2" },
          { at = 40, action = "face" },
          { at = 40, action = "missile", kind = "warden_orb", count = 3, arc = 20, offset = "1.2" },
          { at = 40, action = "set_cooldown", var = "ready", ticks = 70, jitter = 20 },
        } },
      regroup = { anim = 1, move = "stop", face = "target",
        transitions = {
          { to = "chase2", when = { { cond = "var_is", var = "phase", value = 2 } } },
          { to = "chase1", when = { { cond = "has_target" } } },
          { to = "look",   when = { { cond = "has_target", negate = true } } },
        } },
      pain = { anim = 3, move = "stop", face = "hold", ticks = 16, next = "regroup" },
      death = { anim = 4, move = "stop", face = "hold", solid = false, ticks = 100, next = "death",
        sequence = {
          { at = 0, action = "sound", name = "monster.cyberdemon.death" },
          { at = 0, action = "alert_nearby", radius = "40" },
        } },
    },
  },
}
  • Body: radius 0.9, height 3, speed 3, solid. mass 1000 takes a tenth of every shove.
  • The phase check is first in chase1, so crossing half health interrupts whatever it would have done next. var_is phase 1 makes it happen once.
  • Every attack ends in regroup, never in a chase directly. One place decides which phase it is in, and pain goes there too, so a flinch in phase two never drops it back to phase one.
  • The stomp is a swing that does not sweep (sweep_from = sweep_to), wide (a quarter turn each side), coming down from above (pitch_from 0.125 to pitch_to −0.125). target_above with not keeps it from stomping at someone on a ledge.
  • Minions: spawn needs an imp in the module (recipe 1). limit 4 caps how many it has alive at once. count_within with not means "no imps within 20", and chance 5 makes the summon an occasional choice rather than the first one.
  • The effect has no ticks, so the speed-up lasts for the rest of its life. The tag means a second enrage would replace it, not stack.

Make the stomp readable. The boss's stomp is a swing, so the game draws it as a slash streak. On the boss's 💨 slash tab, a red color, width 1 (the whole wedge) and a longer fade such as 0.5 make the danger zone stay on screen long enough to read (Attacks).

6. Gem Hollow's slime: a monster you jump on

Not a recipe to build but one to open: the slime in the example project, as the studio writes it into Gem Hollow's maps/module.lua. It is the platformer's oldest enemy: walk into it and it bumps you; land on it and it bounces you up and is gone. (The pain, death and gone states are shortened here; The brain lists them.)

slime = {
  hp = 20, sight = "14", turn_speed = 8, pain_chance = 200,
  initial = "look", corpse = false,
  vars = { ready = 0 },
  states = {
    look = { anim = 0, move = "wander", face = "movement",
      transitions = {
        { to = "squash", when = { { cond = "target_above", by = "0.6" },
                                  { cond = "target_within", distance = "1.3" } } },
        { to = "chase",  when = { { cond = "has_target" }, { cond = "target_visible" },
                                  { cond = "target_within", distance = "9" } } },
      } },
    chase = { anim = 1, move = "chase", face = "target", interruptible = true,
      transitions = {
        { to = "squash", when = { { cond = "target_above", by = "0.6" },
                                  { cond = "target_within", distance = "1.3" } } },
        { to = "look",   when = { { cond = "has_target", negate = true } } },
        { to = "attack", when = { { cond = "target_within", distance = "1.4" },
                                  { cond = "cooldown_ready", var = "ready" } } },
      } },
    attack = { anim = 2, move = "stop", face = "target", ticks = 24, next = "chase",
      sequence = {
        { at = 10, action = "melee", damage = 10, range = "1.2", knockback = "6" },
        { at = 10, action = "sound", name = "monster.attack" },
        { at = 10, action = "set_cooldown", var = "ready", ticks = 60 },
      } },
    squash = { anim = 4, move = "stop", face = "hold", solid = false, ticks = 40, next = "gone",
      sequence = {
        { at = 0, action = "sound", name = "monster.slime.death" },
        { at = 0, action = "melee", damage = 1, range = "2", lift = "14" },
      } },
    -- pain (12 ticks), death (a sound at 0), gone (despawn at 0)
  },
  drops = { { item = "coin" } },
}
  • Body: radius 0.55, height 1, speed 2.5, drawn with the sheet SLIME.
  • The stomp comes first in both look and chase, so landing on it wins over anything else.
  • The bounce is a 1-point melee with lift 14. The hero loses a point of health and is thrown up, which reads as a bounce.
  • Make it yours: give squash a vfx step at 0 for a splash. Note that a stomped slime drops nothing: drops are rolled only when hits take its hp to 0, and squash ends in despawn instead (Pain, death and drops).

7. Cinderfall's Smelter: a boss in one chase

Another one to open rather than build: the boss of Cinderfall, the first-person shooter example that comes with the studio (Home → ◆ examples; see the tour). Recipe 5 changes phase through a var and two chases. The Smelter does it with one chase whose first card only opens below half health. (pain and death are shortened.)

smelter = {
  hp = 2400, sight = "60", turn_speed = 4, pain_chance = 12, mass = 12,
  initial = "look", corpse = true,
  vars = { ready = 0, slam = 0, brood = 0 },
  states = {
    look  = { anim = 0, move = "stop", face = "hold",
      transitions = { { to = "roar", when = { { cond = "has_target" }, { cond = "target_visible" } } } } },
    roar  = { anim = 7, move = "stop", face = "target", ticks = 60, next = "chase",
      sequence = { { at = 0, action = "sound", name = "smelter.roar" } } },
    chase = { anim = 1, move = "chase", face = "target", interruptible = true,
      transitions = {
        { to = "brood", when = { { cond = "hp_below", percent = 50 }, { cond = "cooldown_ready", var = "brood" } } },

  • Body: radius 1.4, height 4.4, speed 2, drawn with the sheet SMELTER, which has states up to 7 (roar). Placed once, in w_heart_w.
  • The second phase is a card, not a var. hp_below 50 is the first card in chase. Above half health it never matches, and the Smelter only slams and shoots. Below, every 600 ticks (10 seconds) it stops, roars and brings three husks, never more than 9 of its own alive at once (limit). Nothing else changes, so there is no regroup to write.
  • Three cooldown vars, ready, slam and brood, so no attack waits on another's timer.
  • Heavy and hard to stagger. pain_chance 12 (out of 255) flinches about one hit in twenty; and mass 12 makes it heavy to shove, so your scattergun's knockback hardly moves it.
  • The volley is four fans. Each missile step fires a fan, count 3, then 2, 3 and 2, all with arc 8, the degrees between two shells: ten shells in 30 ticks. A fan of 3 goes at −8, 0 and 8 degrees, a fan of 2 at −4 and 4, so each fan fills the gaps of the one before. offset "2" is a distance, not an angle: every shell starts 2 units in front, just clear of the Smelter's radius of 1.4 (Attacks).

A lua condition or action moves a monster to the slower runtime. None of these recipes needs one. The server prints at load how many monster kinds run on the fast C++ loop and how many fall back, with the reason. Keep the escape hatch for what the vocabulary truly cannot say.

Exercise: build the turret

The turret is the smallest recipe. Building it once teaches you how a recipe maps onto the workshop.

  1. Make a prop-like sheet for it, or reuse any sheet with an idle, a fire and a death animation. Open ☠ Monsters, press + new monster and name it turret.

  2. On 👤 body: pick the sheet, set radius 0.5, height 1, speed 0, solid on.

  3. On 🧠 brain: hp 150, turn_speed 0.5, sight 24, mass 1000. Clear pain_chance and switch infighting off.

  4. In the graph, pick pain and press ✕ state. Rename look to scan, chase to track and attack to fire with each state's name box; arrows follow the new names.

  5. Set track's move to stop and its anim to 0. Replace its transitions with the two in the recipe: to fire first, then to scan, with target_visible negated and state_elapsed 32.

  6. Set fire's ticks to 32 and next to track. Delete its old steps. Add three hitscan steps at 8, 16 and 24 (damage 6, range 24, spread 3), a sound at 8, and set_cooldown at 24 on ready, ticks 60, jitter 12.

  7. On death, switch solid on so the wreck keeps blocking, and add a sound at 0. Check "loads clean".

  8. Place two turrets covering one corridor, press ▶ Play, and cross it. Strafe across one's front and watch it fail to keep up. Then compare with turn_speed 4.

The charger dashes with move = "wander". Why not move = "chase"?

  • chase cannot go faster than the body's speed
  • chase keeps steering after the target, so you could not sidestep it; wander walks the heading stored at the end of the wind-up
  • wander ignores walls, so it can break through them

A charge you can dodge must commit to a line. set_angle stores the line once, and wander walks it. Walls still stop it, and stuck notices.

In the boss, why does pain go to regroup rather than to chase1?

  • So a flinch in phase two does not send it back to phase one's chase
  • Because pain may not name a chase state
  • So it cannot be hurt during the flinch

regroup reads the phase var and picks the right chase. Anything that returns to the fight goes through it.

The turret has no pain state, but pain_chance is 128. What happens when you shoot it?

  • It flinches half the time, into its idle animation
  • The workshop refuses it
  • It never flinches: there is no pain state to enter, so nothing is rolled

The pain roll needs a state called pain. Clearing pain_chance as well just says so plainly.
