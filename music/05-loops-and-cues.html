Loops, cuts and cues

Game music has to loop for as long as the player stays, and change when the game changes: a calm piece while you explore, a harder one when the fight starts. Here you cut a song into looping pieces, test the changes in the DAW, then hand the pieces to a map in the studio and switch them from a trigger.

You'll learnhow the loop region becomes loop markers, how to cut slices in Cut & Loop, how to test changes in Cues, and how the studio's Music page and the trigger music action switch music in the game Time25 minutes Needsa project of at least 8 bars (see A tour of the DAW); the studio for the last part

The loop region is the track's loop

The loop region you drag on the Arrange ruler is not only for listening. When loop is on, it is written into the song as two markers, loopStart and loopEnd, in the exported .mid and in the baked .mstk. The game plays the track once up to loopEnd, then goes back to loopStart and loops from there for ever.

So an intro is simply the bars before the loop region: put the loop on bars 5–20 and bars 1–4 play once.

Listen to the seam before you bake: with loop on, the DAW plays the region round and round exactly as the game will.

Cut & Loop

One song can give several pieces. The Cut & Loop tab cuts them:

  • Bake project → load here bakes the whole project in memory, with its bank, kit, effects and mastering, and opens it here. …or load a .mstk opens a baked track from a file instead.
  • On the timeline, drag to select a region; click to move the playhead. With snap to bars ticked, the region snaps to bar lines.
  • ▶ Loop region plays just the region, looping, so you hear how the seam sounds. ▶ Whole track plays everything; ⏹ stops.
  • crossfade ms and ⇄ Crossfade into region: while something plays, fade from it into the region, to hear the change.
  • Type a slice name (it suggests one from the bar number) and press ＋ Add slice.

Each slice in the list shows its bars, length and size, with ▶ loop, ⇄ (crossfade into it), ⬇ (download) and ×. ⬇ Export all slices saves them all, as does File › Export slices (.mstk).

A slice is a complete track of its own, ready for the game:

  • It starts sounding exactly as the song did at that point: the right programs, controllers and tempo.
  • Notes that crossed its edges are closed cleanly, so nothing hangs.
  • It loops whole.
  • It keeps all of its parent's instruments, so slices of one song can crossfade into each other smoothly.

The project remembers each slice's bars. Open the project again later and bake, and the slices are cut again from the new version.

  1. Open Cut & Loop and press Bake project → load here.

  2. Drag across bars 1–4 on the timeline and press ▶ Loop region. Listen to it wrap a few times.

  3. Name it calm and press ＋ Add slice.

  4. Select bars 5–8, press ⇄ Crossfade into region while calm loops, then add it as fight.

Cues: try the changes

The Cues tab plays pieces and switches between them the way the game does. Its pieces are your slices (they appear on their own), plus:

  • ＋ whole project as a piece, which bakes the project and adds it;
  • ＋ import .mstk pieces…, for tracks baked elsewhere.

Each piece has a card. The buttons on it say when that piece takes over:

ButtonWhen the switch lands
▶ nowAt once, a hard cut. Also how you start the first piece.
⏭ at loop endWhen the current piece finishes its loop. The playing card counts down the seconds left.
⏭ next barOn the next bar line of the current piece.
⇄ fadeNow, crossfading over crossfade ms (800 at first).

While a switch is waiting, the card says queued and ✕ cancel queued calls it off. ⏹ stop stops playback.

Chain rules and the entry piece

A card's second row is a rule: then → piece after N loops, at loop end or next bar. When the piece has looped N times, the tab queues the next one by itself. Use it for an intro that plays once and hands over to the main loop, or for two variations that alternate.

Tick entry piece on the card a level should start with. The Transition log records every switch with its song time, so you can check a chain did what you meant.

File › Export cues.json writes the pieces, the entry piece and the rules:

{ "version": 1, "entry": "intro",
  "pieces": [{ "name": "intro", "file": "intro.mstk", "loop": true, "lengthMs": 8000 }, …],
  "transitions": { "intro": { "then": "loopA", "after": 1, "mode": "loopEnd" } } }

The game does not read cues.json or run chain rules yet. In a module, a map's cues come from the studio's Music page and change only when a trigger or script asks (below). Use the Cues tab to try out and tune your pieces.

  1. Open Cues. Press ▶ now on calm.

  2. Press ⏭ at loop end on fight. Watch the countdown on calm's card and the switch land on the loop's end.

  3. On fight's card, set then → calm after 2 loops. Check the log: after two loops of fight, calm comes back.

In the studio: the Music page

In the studio, open ♪ Music from the rail. The page has two parts.

Tracks in the module

Every track the module has, with its size (or not baked yet), how many cues use it, and buttons:

  • + new track asks for a name and opens a new project in DigidreamSynth, right inside the studio. It needs the DigidreamSynth plugin.
  • ✎ edit in DigidreamSynth opens that track's project. Going back to the studio saves it.
  • + import track (.mstk) adds a track baked elsewhere. If the map has no default cue yet, the track becomes it.
  • bake now bakes the project into its track at once. ▶ listens, ■ stops, ✕ deletes the track and every cue that uses it.

A track you make in the studio is kept as its project, sources/music/NAME.msproj. The game plays the baked file, assets/music/NAME.mstk, and the studio makes it from the project when you press ▶ Play or ⇪ Export, or bake now. You never handle the .mstk yourself.

The map's cues

The top part, ♪ map: cues, belongs to the map you have open: every map keeps its own. Each cue is a name and a track. + cue adds one (the first is suggested as default, the next as fight); the list beside it picks the track; ▶ listens; ✕ removes the cue.

  • The cue called default starts with the map. A map with cues but no default gets a warning when you play or export.
  • The others play only when a trigger or a script asks for them by name.

The studio writes all maps' cues into assets/music/index.json, keyed by the map's name:

{
  "map01": {
    "default": "theme_calm.mstk",
    "fight": "theme_fight.mstk"
  }
}

Music is not set in module.txt. There are no music lines there; everything comes from the Music page and its index.json.

Cut a map's cues from one project in Cut & Loop. Slices of one parent share their instruments, so the game crossfades between them on the beat. Unrelated tracks are swapped instead.

Switching music from a trigger

A trigger's music action changes the cue. Its fields:

FieldMeaningWhen left out
cueA cue name from this map's list.required
fadeCrossfade length in ms.800
atnext_bar, loop_end or now.next_bar
everyoneEvery player in the level, not just the one who set it off.only that player

Here is a trip-wire that starts the fight music for everyone when a player crosses into an arena, written as the trigger table the studio saves:

{ name = "arena music",
  event = "on_cross",
  once = true,
  conditions = {
    { c = "side_is", side = 12 },
    { c = "entity_is_player" },
  },
  actions = {
    { a = "music", cue = "fight", at = "next_bar", fade = 800, everyone = true },
  } },

A Lua script can do the same with dnp.music(who, cue, fade, at). Pass a player for who, or nil for everyone in the level:

dnp.music(nil, "fight", 800, "loop_end")
  • A cue the map does not have is not an error in the game; it is named in the client's log and the music carries on.
  • A cue change is a moment, not a state: a player who joins later starts on default.
  • Without everyone, an event with no player (a timer, say) sends nothing.

  1. On the Music page, give your map a default cue with the calm track and a fight cue with the fight track.

  2. In the map editor, add a trigger on a doorway into a room, with the music action: cue fight, at next_bar. (Triggers are covered in Triggers.)

  3. Press ▶ Play. The map starts on calm; walk through the doorway and the music turns to fight on the next bar.

A trigger's music action has only cue = "fight". When does the change land, and for whom?

  • At once, for everyone
  • At the end of the loop, for the player who set it off
  • On the next bar, crossfading over 800 ms, for the player who set it off

The defaults are at = next_bar, fade = 800, and the event's player unless everyone is set.

Which cue does a map start with?

  • The one called default
  • The first one in the list
  • The one set with entry piece in the DAW's Cues tab

The game starts each map on its default cue from assets/music/index.json. The DAW's entry piece is for testing.

You edited a track's project in DigidreamSynth from the studio. When is its .mstk made again?

  • Only when you export it from the DAW's File menu
  • At Play, at Export, or when you press bake now
  • Every time you press a key in the DAW

The studio keeps the project as the source and bakes the track the game loads from it whenever it would otherwise be stale.
