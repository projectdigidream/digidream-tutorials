A tour of the DAW

DigidreamSynth is the module's music tool: a small DAW built on the same synth engine the game runs. What you hear while you edit is exactly what the game will play, because the file you hand the game is made by that engine too.

You'll learnhow to start the DAW, what the header, the File menu and the transport do, how the tabs are laid out, how Arrange works, and which file is which Time15 minutes Needsa checkout of the repository with Node.js (and Emscripten once, to build the engine), or the studio with the DigidreamSynth plugin

Four ways to run it

The DAW is one web page, midisynth/tool/daw.html. The same page ships in four shells:

WhereHowNotes
Browsernode tool/serve.js, then localhost:8930/tool/daw.htmlNeeds a click on Start audio before anything sounds.
Desktop appcd midisynth/electron && npm install once, then npm startNative menus and dialogs, file associations, no Start-audio click.
Android./scripts/package_android.sh builds an APKSaved files land in Documents/. A WebView has no Web MIDI, so no MIDI keyboard.
Inside the studiothe ♪ Music page, ✎ edit in DigidreamSynthThe same DAW as a plugin, in the studio's skin. It starts by itself (no Start audio) and has no File menu: ‹ studio saves the project and goes back, ✕ goes back without saving. See Loops, cuts and cues.

The same server also hosts two smaller tools: the stand-alone patch editor at /tool/ and the track cutter at /tool/cutter.html. The DAW has both inside it, as the Synth and Cut & Loop tabs.

  1. Build the engine once. The DAW plays through a WebAssembly build of the synth, and this script makes it (it needs Emscripten):

    cd midisynth
./scripts/build_wasm.sh

  2. Start the static server and open the DAW:

    node tool/serve.js
# http://localhost:8930/tool/daw.html

  3. Press Start audio. Browsers only allow sound after a click, so the page waits for one. A progress bar shows the boot stages, and the log at the bottom ends with "DAW ready — draw notes in Track, record with ● Rec, bake in File › Bake .mstk".

The header

Everything along the top applies to the whole project, whatever tab you are on.

  • File and Edit menus. Edit holds Undo, Redo and a history list of the edits you made.
  • The project name (untitled at first). It becomes the file name when you save.
  • ↶ and ↷: undo and redo, also ⌘Z and ⇧⌘Z.
  • The transport (below), then voices, a count of the synth voices sounding, and the MIDI state.
  • A volume slider at the far right. It changes what you hear, not what you export.

On a phone, or in any window under 700 px wide or 520 px tall, the header collapses to one line with play, stop and the position. Tap ▾ to open it.

The File menu

The File menu is in the browser, desktop and Android versions. Inside the studio it is hidden: the studio keeps the project and bakes the track itself (see the Music page). The log line "bake in File › Bake .mstk" still shows there; ignore it.

You can also drag any of these files onto the page. A .msproj opens, a .mid or .mstk imports, and a .json is recognised as a bank, kit, fx or master file by what is in it.

The transport

ControlWhat it does
▶Play from the playhead. Space plays and stops.
⏹Stop and return to the start.
● RecRecord from a MIDI keyboard onto the armed track, with a count-in. R does the same. See Recording.
Position1.1.000 is bar 1, beat 1, tick 0. Beside it, the time in minutes and seconds.
bpmTempo, 20 to 400.
sigTime signature: beats per bar, and the note value of a beat (2, 4, 8 or 16).
loopPlay the loop region over and over. On by default.
clickThe metronome. It plays on the drum channel during playback and is never exported.
count-inBars of click before recording starts, 0 to 8.
snapThe grid notes snap to: 1/1 to 1/32, the triplets 1/8T and 1/16T, or off.
swingA grid (1/8, 1/16, 1/32) and a percentage. Every second note on that grid is played late; 100% is a full triplet shuffle.

Swing never moves your notes. They stay where you drew them, and the delay is added when the song is played or baked. Set swing back to 0 and you have the straight pattern again.

Arrange

One track is one MIDI channel, so a project has at most 16 tracks. Channel 10 is always the drum kit. Each row in the track list has:

  • a colour swatch and the track's name, which you can edit in place;
  • M mute, S solo, R arm for recording;
  • ♪, which opens this track's instrument in the Synth tab;
  • ×, which deletes the track;
  • the MIDI channel (ch 10 (drums) is the kit) and the GM program it plays. The program list is greyed out on channel 10.

＋ track adds a track on the first free channel, skipping 10, playing program 0. A lit dot beside a track means the engine is playing a note on it right now.

In the lanes

  • Click a lane to move the playhead there and select that track.
  • Double-click a lane (or a row of the track list) to open it in the Track tab.
  • Drag on the ruler to set the loop region. It snaps to whole bars and turns loop on.
  • ⌘ + wheel zooms; the zoom slider does the same. The wheel alone scrolls through time.

You can edit while the song plays. Every change goes to the engine at once, keeping the playhead where it is: a deleted note releases normally, and a new note under the playhead is struck.

  1. Press ＋ track twice. In the second row, open the channel list and choose ch 10 (drums).

  2. Drag on the ruler from bar 1 to bar 5. The region shows on the ruler, and loop is ticked.

  3. Double-click the first lane. The Track tab opens on that track. Draw a few notes (the next page explains how), go back to Arrange and press Space.

  4. While it plays, press M on the track, then S. Then press ⌘S to save the project as a .msproj.

Importing a MIDI file

Drag a .mid onto the page, or use Import .mid / .mstk…. What changes:

  • Replaced: the tracks, the tempo map, the time signatures and the loop. If the file has loopStart and loopEnd markers, they become the loop region; if not, the loop is the whole song.
  • Kept: the project's bank, kit, effects and mastering. Your patches survive a re-import.

Importing a .mstk works the same way for the notes, but the baked track also carries its own bank, kit, effects and mastering, and those come in with it.

Import replaces every track. Save first if the project has work you want to keep, or use Edit › Undo after.

  1. Drag a .mid file onto the DAW. The log says how many tracks and notes came in.

  2. Check the track list. Each MIDI channel of the file is now one track, with the program the file chose.

What an import keeps, and what to look out for:

  • The names are whatever the file said. Some are short labels (basu, ovr, drm), some are just MIDI out #3, and in title the composer's credits ended up as track names: MIDIs for Freedoom, Tyler P., "picklehammer". In heart and victory the drum track carries the song's title. Rename them once you know what they play.
  • The resolution is the file's. title keeps 600 ticks per beat; the others have 96. It changes nothing you hear.
  • The loop is the whole song, since none of the files has loopStart/loopEnd markers. Every track restarts from bar 1 with no intro.
  • Only channel 10 is drums. railhead uses channel 11 as well, as an ordinary guitar track, and keeps MIDI out #4, a track with no notes at all.
  • Every project has the shipped bank and kit, the same as Gem Hollow's, so the guitars, choirs and orchestra hits of these metal tunes are played by the stock patches. See Patches for what that means for programs the bank does not have.

  1. Import Cinderfall, open ♪ Music and press ✎ edit in DigidreamSynth on boss.

  2. Play it with Space. Watch squ come in at bar 5 and rain at bar 9: the build-up is in the file.

  3. Rename ovr to guitar L and ovr #2 to guitar R. Leave with ✕ to throw it away, or ‹ studio to keep it.

Keys

You tuned a lead patch for an hour, then import a new version of the song as a .mid. What happens to your patch?

  • It is replaced by the General MIDI default
  • It stays: importing a .mid replaces tracks, tempo and loop, but keeps the bank, kit, effects and mastering
  • It is saved into the .mid file

A MIDI file has no sounds in it, so the project keeps its own. Only a .mstk import brings sounds with it.

Which file does the game play?

  • The .msproj
  • The .mid with a bank.json beside it
  • The .mstk

The .mstk is the baked track: notes, sounds, effects and mastering in one file, checked when it is made.

You drag across the ruler from the middle of bar 2 to the middle of bar 4. What is the loop region?

  • Whole bars, snapped to the nearest bar lines
  • Exactly where you started and stopped
  • Snapped to the snap grid in the header

The ruler always snaps the loop to bars, whatever the snap setting, because a loop that does not end on a bar line stumbles when it repeats.
