Make a game in Digidream Studio

The studio is the editor that ships inside the game. It covers maps, monsters, weapons, cameras and graphs. Four editors run inside it as plugins: ThreeSprite for sprites, qPainter for textures, DigidreamSynth for music and DigidreamSound for sound effects. These tutorials take you through all five, step by step.

How the pieces fit

Each editor saves a source, a project you can open and edit again, into the module's sources/ folder. The studio bakes each source into what the game loads, in assets/. Files and baking covers this in detail.

Before you start

  • Everything here runs from a checkout of the repository with Node.js, or from a built Digidream Studio app for macOS, Windows, Linux or Android.
  • Every editor can also run on its own, outside the studio. Each track explains how.
  • Your progress (ticked steps) is kept in this browser only.
  • Press / anywhere to search.
