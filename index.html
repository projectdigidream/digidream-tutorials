Make a game in Digidream Studio

The studio is the editor that ships inside the game. It covers maps, monsters, weapons, cameras and graphs. Four editors run inside it as plugins: ThreeSprite for sprites, qPainter for textures, DigidreamSynth for music and DigidreamSound for sound effects. These tutorials take you through all five, step by step, using Gem Hollow, the example game that ships with the studio, as the running example. All you need is the studio app for Windows, macOS, Linux or Android: get the tools.

How the pieces fit

Each editor saves a source, a project you can open and edit again, into the module's sources/ folder. The studio bakes each source into what the game loads, in assets/. Files and baking covers this in detail.

Before you start

  • Everything here needs only the Digidream Studio app for Windows, macOS, Linux or Android. Get the tools says which download to pick and how to install it. You never build or compile anything.
  • Every editor can also run on its own, outside the studio, as a standalone app. Each track explains how.
  • The screenshots show the studio in its default style, Claude, dark. The studio can wear other styles (Settings → Look, or the Style card on Home), which change its colours and icons but not its labels.
  • To follow along with real content, open Gem Hollow (or Cinderfall, the newer example) from Home → examples. You get your own copy to change freely, and a fresh copy gives you a clean one again.
  • Your progress (ticked steps) is kept in this browser only.
  • Press / anywhere to search.
