All shortcuts

Every key in the five tools, in one table. Type to filter, or pick a tool.

On Windows and Linux, use Ctrl in place of ⌘. In a plugin running inside the studio, the editor's own keys work while its frame has focus. The studio's undo keys work only outside the plugin.

Practise

Pick a tool's trainer. It names an action, and you press the key.
