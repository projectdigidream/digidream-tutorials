All shortcuts

Every key in the five tools, in one table. Type to filter, or pick a tool.

On Windows and Linux, use Ctrl in place of ⌘. In a plugin running inside the studio, the editor's own keys work while its frame has focus. The studio's undo keys work only outside the plugin.

The map editor's letter and number keys count only on their own. Held with ⌘, Ctrl or Alt, a key belongs to some other shortcut, so ⌘V no longer switches the map to the game view: only V does.

Some of the studio's keys are in the development releases only, so far: studio 0.4.2.1 G, the grid on or off; studio 0.4.2.7 F4 in the game, the colliders; studio 0.4.2.8 Shift+click, Shift+drag, ⌘A, ⌘C, ⌘V and ⌘D for several rooms at once; studio 0.4.2.11 X, the sector effects shown or hidden. The map's ⋯ menu → Help lists the keys of the studio you have.
