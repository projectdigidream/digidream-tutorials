Every graph node

Every node the engine accepts in a graph, with its flow and data pins and its arguments. Below them are the entity properties a graph can read and set, and the graph file's own fields. The list is generated from the engine's own vocabulary (graph_vocab.json), so it can't disagree with what the game runs.

How to read an entry. Flow in / out are the white pins that decide what runs next. Data in / out are values passed along a link. Arguments are what you type into the node's form. Some arguments can also take a data link in place of a typed value. A starts a run node is an event, and level only means a module's game graph can't use it. New to graphs? Start with Thinking in graphs.

Built by node tutorials/tools/build-vocab.mjs from engine/maps/scripts/graph_vocab.json. Re-run it when the engine's vocabulary changes.
