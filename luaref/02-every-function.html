Every function

Everything a script can call, define or read, in one searchable list. Every name here exists in the engine the studio ships, and every name the engine gives a script is here.

How to read an entry. The first line is the signature: what you write, with arguments in square brackets when you may leave them out, and → before what it returns. The badge says which Lua machine has it: level (each level's own), game (the one game-wide machine) or level + game. Open an entry for its arguments, return value, notes and an example. The # on the right is a link to that entry you can copy and share.

Methods are written with a colon, the way you call them: e:pos() for an entity, p:name() for a prop, s:floor() for a sector. Hooks are functions you define, not ones you call. New to all this? Start with The Lua environment, or the Advanced track.
