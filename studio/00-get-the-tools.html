Get the tools

Everything in these tutorials runs in apps you download, and there's nothing to compile. Get Digidream Studio first: it includes the sprite, texture, sound and music editors, so for most people it is the only download.

You'll learnwhich download you need, how to install it on your system, how to get past the warning the first launch shows, and where your work is kept Time10 minutes Needsa Windows, macOS or Linux computer, or an Android phone or tablet

Install it

The apps are not signed by Microsoft or notarized by Apple yet, so the first launch shows a warning. The steps below get you past it once; after that, the app opens normally.

Windows

  1. Unzip Digidream Studio-windows-x64.zip: right-click it, Extract All…. Put the folder somewhere you keep apps.

  2. Open the folder and double-click Digidream Studio.exe.

  3. If Windows says "Windows protected your PC", click More info, then Run anyway.

macOS

  1. Double-click the .zip to unpack it, and drag Digidream Studio into Applications.

  2. Open it. The first time, macOS says "Apple could not verify…". Click Done.

  3. Open System Settings → Privacy & Security, scroll down to the message about Digidream Studio, and click Open Anyway. Confirm with your password. From then on it opens like any app.

Linux

  1. Unpack the archive: tar xzf "Digidream Studio-linux-x64.tar.gz", or open it with your file manager.

  2. In the Digidream Studio folder, run the launcher, the file without an extension next to the .png icon (it is currently named starter). From a terminal: ./starter.

Android

  1. Download the .apk on the phone or tablet, and tap it in your downloads.

  2. If Android asks, allow your browser or file manager to install unknown apps, then go back and tap Install.

  3. If Play Protect warns about an unknown developer, tap More details → Install anyway.

The studio is built for touch as well as a mouse. On a phone held upright there is no rail: Home is the list of sections. See Getting started.

Where your work is kept

  • Your modules live inside the app, on this device. There is no account and nothing is uploaded, unless you turn on Sync with GitHub, which keeps them in a GitHub repository of yours.
  • The studio takes snapshots of a module as you work, and you can restore one from Home → 🕘 snapshots.
  • To back up a module, or move it to another device, press ⇪ export on Home. It saves the whole module as one pack file. On the other device, ⇩ import pack opens it.
  • The example projects, Gem Hollow and Cinderfall, come with the studio: Home → examples. Opening one makes a copy of your own, so you can't break the original.

Updating

The studio tells you when a newer one is out. It asks its releases on GitHub at most every six hours, and never gets in your way: offline, it just says nothing. When a later release exists, Home shows a card, "Studio 0.3.3 is out (you have 0.3.2)", with a short list of what changed and two buttons:

  • ⇪ download opens the release page in your system's browser, where you pick the download for your device.
  • not now hides the card until an even later release comes out.

To ask straight away, press check for updates beside the version on Home (studio 0.3.2). It answers on the button itself: up to date (… is the latest), or could not check: … when GitHub could not be reached. If there is a newer release, the card appears.

To update, download the newer release and install it the same way, over the old one. Your modules stay: they belong to the app's storage on the device, not to the folder you unpacked. Export a pack first if you want to be safe.

If Home doesn't offer an example these tutorials mention, such as Cinderfall, your studio is older than the tutorials. Download the latest release.

You want to draw sprites and paint textures for your game. What do you download?

  • ThreeSprite and qPainter, then the studio
  • Just Digidream Studio: it includes both editors
  • The Packager

The studio opens ThreeSprite and qPainter itself, from its Sprites and Textures pages. The standalone apps are for working outside the studio.

macOS says "Apple could not verify…" and won't open the studio. What now?

  • Download it again: the file is damaged
  • Install the Intel version instead
  • System Settings → Privacy & Security → Open Anyway

The app is signed but not notarized by Apple, so macOS asks once. Open Anyway lets it run from then on.
