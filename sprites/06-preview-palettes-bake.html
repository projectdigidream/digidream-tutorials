3D preview, palettes, baking

The last steps before a sprite goes into the game: walk round it in 3D to catch a view that jumps, keep its colours in order, set how tall it stands, and know what the studio makes from it.

You'll learnthe 3D tab and its controls, the palette editor and palette files, Project settings, what the bake makes and how tall the sprite stands, the Export tab, and what is inside a .tsprite Time25 minutes Needsan animated sprite (see Animating)

The 3D tab

The 3D tab stands the sprite on a ground grid as a billboard, the way a game shows it. Orbit the camera and the picture swaps between views, exactly as a game picks a view from the camera's bearing. On a desktop the tab also shows a drawing canvas for every view you draw, so you can fix a view while you watch it turn. The tools and the palette are there too.

Drag in the scene to orbit, and use the wheel to zoom. In the scene, a readout says Camera sees view k · Front-left 45°, or whichever view it is.

ControlWhat it does
Animation and Play / pausePlays the chosen animation in 3D (Space). The slider beside it scrubs frames.
Facing N°Turns the character, anticlockwise seen from above, without moving the camera.
Spread NShows N copies side by side, one facing each way, so every view is on screen at once. Facing is greyed out while it is on.
Facing arrows and labelsDraws an arrow on the ground where each copy faces, and a label with the view it shows (view 3, or 90° → view 3 when spread).
Reset cameraPuts the camera back where it started.

Here is the same sum on paper. With 16 views and mirroring, turn the character with Facing and watch which view the camera picks, and whether it is one you drew.

  1. Open 3D and tick Spread 8 (or however many views you have). Turn on Facing arrows and labels.

  2. Check the copies read 1 to N in order, each one turned a step further anticlockwise. A view drawn facing the wrong way stands out at once.

  3. Untick Spread. Press Space to play, and orbit slowly round the sprite. Watch the readout as each view swaps in. Look for a limb that jumps between two views.

  4. When one view looks wrong, paint on its canvas at the side while the 3D keeps playing.

Palettes

A project holds any number of named palettes, and one is active in the Draw tab. A new sprite starts with DawnBringer 16. The palette button in the palette panel (Palettes: switch, edit, import) opens the Palettes editor:

  • At the top: the active palette, and New, Duplicate, Rename and Delete. A project keeps at least one palette, and deleting one leaves the pixels' colours as they are.
  • The swatches: click one to select it. + adds a colour after the selected one. Then Move left, Move right, Remove colour (pixels keep it), Sort (dark to light) and Add colours from artwork, which appends every colour painted in the project that is not in the palette yet.
  • Selected colour: a big swatch that opens the system colour picker, a hex field, R, G and B sliders, and Use as brush colour.
  • Recolour pixels in every image when a swatch changes: with this ticked, editing a swatch repaints every pixel painted in that colour, in every part, variant and view, live as you drag. It is one undo step.
  • New palette from a preset: DawnBringer 16, DawnBringer 32, PICO-8, Sweetie 16, Endesga 32, Game Boy and Greyscale 16.

Palette files

Import… has two choices: Replace: as a new palette…, or add only the missing colours to the palette you are on. It reads:

  • .hex (Lospec), .gpl (GIMP, Aseprite, Krita) and .pal (JASC);
  • a .png swatch strip, or any image, whose colours are taken in the order they appear (reduced past 256);
  • the palette inside a JSON project, including qPainter's .texproj.json.

Export… writes .hex (Lospec), .gpl (GIMP, Aseprite), .pal (JASC) or .png swatches, of either the Whole palette or only the Colours the sprite uses. These are the formats qPainter reads and writes, so a palette moves between sprites and textures as a file.

A shared module palette, assets/palette.json, that every tool would read is planned but not started. For now, keep sprites and textures matched by exporting a palette file from one tool and importing it in the other.

Project settings

Click the project's name in the top bar, or the gear, for Project settings:

FieldWhat it does
Name, Sprite idAs in the New sprite dialog.
CanvasShown, not editable: it is fixed after creation.
Views, Mirror symmetryChange the view count or mirroring. A warning says that images drawn for views that no longer exist are dropped. It is undoable.
Camera elevationDegrees above the horizon that every view's camera looks down from, for bones and solids. 0 is level.
Depth scaling0 (off) to 40. How much a bone travelling towards the camera grows what hangs off it, and travelling away shrinks it. 1 is barely visible; 5–20 is where it reads. The rest pose never changes size.
World heightHow tall the sprite stands in the world, in units. It is written into the sheet's manifest.

Baking in the studio

Inside the studio you don't use the Export tab. Pressing ‹ studio saves the project as sources/sprites/NAME.tsprite and bakes it into assets/sprites/NAME.json and NAME.png. Play and Export bake again any sprite whose project changed. ThreeSprite's own runtime composes the sheet, in the same layout as its Atlas + JSON export: every view of every frame, mirrored views included, trimmed and packed, with each frame's feet, every animation's fps and loop, and the world height. To take a sprite out of the studio, its card on the Sprites page has export .tsprite (the project) and export sheet (the baked sheet, NAME-sheet.zip of json + png, which imports again), and duplicate copies all of it under a new name.

  • The sheet is named after the studio's name for it, whatever the project's sprite id says.
  • Props and monsters choose a sheet by that name. In a monster's body card, sprite sheet picks it, and the five states are matched to its animations.

How tall it stands

The manifest's world height is the one number the game scales every frame of the sheet by. In the studio, a monster's body card shows it as sprite height. Changing it there rewrites the sheet's manifest, and every monster drawn with that sheet grows with it. A body's scale multiplies the size for that body alone.

A bake writes the world height from the ThreeSprite project. If you set sprite height in the studio and later edit the sprite and press ‹ studio, the project's World height comes back. Set the same number in Project settings to keep it.

  1. In ThreeSprite, open Project settings and set World height to 1.5. Press Apply, then ‹ studio.

  2. In the studio, open a monster's body card and choose your sheet under sprite sheet. Its sprite height reads 1.5, and the preview stands it against a ruler.

In Cinderfall

Cinderfall, the first-person shooter example, comes with the studio: on Home, under ◆ examples, press 📂 Cinderfall. The Cinderfall tour walks round it.

One small palette each

Each of the 57 sprites carries a single palette named after it: GUNNER colours has 16 swatches, HUSK's 19, MAGS's 12, SMELTER's 9 and SPITTER's 6. Every part is made of solids, so the palette is the set of colours the shapes are painted with: rust, soot, khaki, a little brass. A few colours per sprite is what makes them read as one dirty, worn town.

Weapons in first person

The five VM_ sprites are baked like any other sheet. The Weapons workshop's first person tab then picks, for each weapon, the sheet, the at rest (fallback) and firing (fallback) animations, and one animation per state its phases set. For the revolver it saved:

sheet    VM_REVOLVER   at rest: ready   firing: fire   scale 1.4   canvas at 96, 40
state 13 → fire     (set by the fire phase)
state 14 → cock     (set by the cock phase)
state 15 → reload   (set by the reload phase)

Every weapon uses scale 1.4 at x 96, y 40, so all five sit in the same place on the 320 × 200 screen. The riveter's fire state is set to loop, for as long as the trigger is held. See Phases in first person.

  1. Open Cinderfall's SMELTER in ThreeSprite, open the 3D tab and drag round it. Then open Project settings: World height reads 9.21.

  2. Set it to 7, press Apply and ‹ studio. Play to the boss arena in w_heart_w: the boss is smaller, but it fills as much floor as before, since its body did not change.

  3. Undo it on the studio's page with ↶ Undo.

The Export tab (standalone)

On its own, ThreeSprite writes files from the Export tab. Pick a format, tick the animations to include, set the format's option, and check the file list on the right before writing.

FormatWhat it writesLimits and options
Doom-style PNGsOne PNG per frame and view, named sprite id + frame letter + rotation (TSPRA1.png …). Rotation 1 faces the viewer, then anticlockwise.Needs a sprite id of exactly 4 letters or digits in capitals; 1, 8 or 16 views; and at most 26 frames across the chosen animations (A–Z). Front view only (rotation 0) exports view 1 alone for other view counts.
Atlas + JSONOne packed sheet of trimmed frames, plus a JSON manifest with rects, feet pivots, animations and every view's angle.Power-of-two sheet height
PNG framesA folder per animation with one full-canvas PNG per frame and view, such as sprite/anim/000_v01.png. No manifest.—
GIF previewsAn animated GIF per animation and view, plus a turntable cycling every view of the first frame.Turntable fps. GIF timing is in hundredths of a second, so some fps values play slightly off; the panel says so.

Mirrored views are written as real files in every format. The buttons depend on where ThreeSprite runs: Export to folder… and Export as zip… on the desktop, Save zip… on Android, and Download zip in a browser.

Inside a .tsprite

A .tsprite is a zip:

project.json                    the whole project, with pictures replaced by file references
parts/<part>/<variant>/v<k>.png    one lossless PNG per part, variant and drawn view k
thumbnail.png                   a small preview

The current format is version 3, and older files are upgraded when opened. Only the views you draw are stored: flipped views are made when the sprite is composed.

You want Doom-style PNGs from a 12-view sprite with all 12 views. What happens?

  • It exports 12 rotations
  • It refuses: Doom-style naming needs 1, 8 or 16 views, unless you export the front view only
  • It exports 8 of the 12

Doom names carry a rotation digit, and only 1, 8 and 16 views map onto it. Change the view count, choose Front view only, or use Atlas + JSON.

You set a sheet's sprite height to 2 in the studio, then edit the sprite and press ‹ studio. The project's World height is still 1. How tall is the sheet now?

  • 2, because the studio remembers it
  • 3, the two added together
  • 1, because the bake writes the project's world height

The bake makes the manifest from the project. Set World height in Project settings to the height you want.

In the 3D tab, Spread is on. Why can't you move the Facing slider?

  • Spread sets each copy's facing itself, one per view
  • The animation is playing
  • Facing only works with mirror symmetry off

Spread turns copy i to i/N of a turn, so that every view is on screen at once. Untick it to turn the character yourself.
